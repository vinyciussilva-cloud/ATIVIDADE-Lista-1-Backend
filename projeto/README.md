# Lista 1 - Backend (PHP)

Atividades de **Conceitos básicos de PHP** — Curso Técnico em Desenvolvimento de Sistemas (SENAI).

## Exercícios

| # | Arquivo | Descrição |
|---|---------|-----------|
| 1 | `exercicio01_desconto.php` | Cálculo de preço com 10% de desconto para compras ≥ R$ 200,00 |
| 2 | `exercicio02_aprovacao.php` | Verificação de aprovação (média ≥ 6,0 **E** faltas ≤ 15) com `&&` |
| 3 | `exercicio03_tabuada.php` | Tabuada (1 a 10) de um número com estrutura `for` |
| 4 | `exercicio04_notas.php` | Vetor com 5 notas: média da turma, maior e menor nota (`foreach`) |
| 5 | `exercicio05_imc.php` | Função `calcularIMC($peso, $altura)` com classificação do IMC |

## Como executar

Pasta com os Arquivos
php exercicio_01_desconto.php
php exercicio_02_aprovacao.php
php exercicio_03_tabuada.php
php exercicio_04_notas.php
php exercicio_05_imc.php
```
