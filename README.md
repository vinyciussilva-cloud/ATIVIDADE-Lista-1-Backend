# ATIVIDADE-Lista-1-Backend
Atividade de backend com 5 desafios práticos: cálculo de desconto de 10% para compras desde R$200; checagem de aprovação (média ≥6 e faltas ≤15) com &amp;&amp;; tabuada de 1 a 10 com for; processamento de array com 5 notas (média, maior e menor); e função de IMC. Resolva usando o material base e envie o link do seu repositório para pontuar.
